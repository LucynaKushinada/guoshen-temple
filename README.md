# 过审祈福殿

和朋友一起在线礼佛，为《非常了不起的修仙模拟 · 炼气篇》祈求早日过审。

打开网页：https://lucynakushinada.github.io/guoshen-temple/

## 能做什么

- **上香、叩首、敲木鱼、求签（32 支）、许愿、还愿**
- **撞钟**：全殿都听得见。
- **御剑**：玄天剑拖着流光绕殿一周，最后撞响大钟。
- **烟花**：在殿顶放一场烟花。
- **天灯**：在殿顶飘 30 分钟。
- **供品**：摆 3 小时。
- **弹幕祈福**
- **修为**：从凡人修到炼气、筑基、金丹、元婴、化神，突破时有**渡劫**动画：乌云压顶、天雷劈落、金光柱降下，全殿一起看。
- **佛光普照**：合寺功德跨过里程碑时触发，还有仙鹤成群飞过。
- **昼夜天象**：随本地时间变化——白天有光柱和浮尘，傍晚是晚霞，夜里有星空、弯月和萤火。
- **体感视差**、**同心叩首**、**今日运势**、**功德证书**、**禅音**

## 反作弊（严格）

网页没有服务器，所以每个人的浏览器都会独立核验别人的数据：

1. **签名身份**：每个浏览器生成一把 ECDSA P-256 私钥，香客编号由公钥算出。所有存档、操作和通报都必须签名，谁也冒充不了谁，也陷害不了谁。
2. **按天记账**：功德按天分项记录，每项每天有上限。以木鱼为例，每天最多 2000 下；所有项目加起来，一天最多约 3000 功德。
3. **速率核验**：拿同一个人前后两份签名存档对比，涨幅必须是那段时间内可能达到的。
4. **公开证据**：一旦违规，作弊者自己签名的违规存档会作为证据公开。任何人都能复核，后进殿的人也能看到。处罚是全殿通报、天雷劈下、功德罚没、逐出山门。
5. **防删档**：有人删掉别人的存档时，其他浏览器会用原主签名的存档把它恢复。
6. **连点器**：
   - **脚本代点**是铁证，当场处罚。
   - 下面三条靠统计推测，门槛都定在真人做不到的程度。第一次只警告，这一下不计功德；十分钟内再犯才处罚。
     - 2 秒内敲 36 下以上
     - 连续 60 下，间隔几乎分毫不差（按事件自带的时间戳计时，手机屏幕刷新不会造成误判）
     - 触屏连续 50 下落在同一个像素

   处罚：第一次作废当天功德，另罚 999；第二次逐出山门。

   v3.0 的连点判定太严，误伤过真人。那一版凭推测给出的处罚已全部撤销，本人打开新版网页后会自动恢复功德。
7. 同一浏览器只允许一个标签页操作。

作弊的人最多只能刷到每天的上限，也就是和天天打满上限的玩家持平。
