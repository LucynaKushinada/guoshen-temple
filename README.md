# 过审祈福殿

和朋友一起在线礼佛，为《非常了不起的修仙模拟 · 炼气篇》祈求早日过审。

打开网页：https://lucynakushinada.github.io/guoshen-temple/

## 能做什么

- **上香 / 叩首 / 敲木鱼 / 求签 / 许愿**：香插在同一个香炉里，大家一起看着它烧；签筒里有 32 支签。
- **撞钟**：谁撞一下，全殿都听得见。
- **放天灯**：写一句心愿，天灯在殿顶飘半个时辰（30 分钟），点一下能看到是谁写了什么。
- **供品**：苹果、寿桃、橘子、寿包、清茶、莲花灯、鲜花，在供桌上摆三个时辰（3 小时）。
- **弹幕祈福**：一句话从所有人的大殿画面上飘过。
- **修为与功德榜**：按个人功德，从凡人修到炼气、筑基、金丹、元婴、化神，突破时全殿通报。
- **同心叩首**：两个人 3 秒内一起叩首，各得 5 点功德。
- **今日运势**：每人每天一张，附宜忌。**功德证书**：生成图片，长按保存。
- **禅音**：背景音乐。**自动敲木鱼**：只图个响，不计功德。

## 殿规（防连点器）

木鱼只认亲手敲。遇到以下任何一种情况都算走火入魔：
- 脚本代点
- 2 秒超过 32 下
- 节奏整齐得不像人
- 触屏落点纹丝不动
- 连续八分钟不停手

走火入魔的处罚：
- 本轮连击作废，另罚功德（108 / 324 / 999，按次数加重）。
- 禅定罚坐（1 / 3 / 10 分钟），期间木鱼不计功德，刷新页面也逃不掉。
- 全殿通报，功德榜上标「入魔×次数」。

## 说明

- 手机和电脑的浏览器都能用，不用注册账号，第一次进殿留个法号就行。
- 同一个网址进来的人都在同一座殿里。想另开一座，在网址后面加 `#殿号`（4–32 位小写字母、数字或短横线），例如 `…/guoshen-temple/#our-team`。
- 联机走 EMQX 的免费公共 MQTT 服务器（`wss://broker.emqx.io:8084/mqtt`），消息是公开的，别写隐私；服务器也不保证永久保存数据。
- 没有服务器校验，防连点器只防君子；整个网页就是一个 `index.html`。
