# 过审祈福殿

和朋友一起在线上香、叩首、敲木鱼、求签、挂许愿牌，为《非常了不起的修仙模拟 · 炼气篇》祈求早日过审。

打开网页：https://lucynakushinada.github.io/guoshen-temple/

- 手机和电脑的浏览器都能用，不用注册账号，第一次进殿留个法号就行。
- 同一个网址进来的人都在同一座殿里。想另开一座殿，在网址后面加 `#殿号`（4–32 位小写字母、数字或短横线），例如 `…/guoshen-temple/#our-team`。
- 联机走 EMQX 的免费公共 MQTT 服务器（`wss://broker.emqx.io:8084/mqtt`）。上面的消息是公开的，别在许愿牌里写隐私。
- 功德、许愿牌和功德簿存在服务器的保留消息里；公共服务器不保证永久保存。

整个网页就是一个 `index.html`，没有构建步骤。
